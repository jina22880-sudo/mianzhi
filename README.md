## 为什么做这个

很多药娘不知道自己的女性化程度。

市面上没有专攻这个方向的软件——要么是笼统的"颜值打分"，要么是医美机构的引流工具，没有一个认真回答"我这张脸在几何上离女性化有多近"。

**这个软件就是做这件事的。开源，免费，不联网。**

---

## 它做什么

首页左右两栏，两种模式：

### ◐ 女性化程度

拍照或选图，给出两个分数：

- **女性化程度**（0.00–10.00）—— 7 项面部骨骼与五官几何
- **颜值分**（0.00–10.00）—— 比例协调度

### ◇ 颜值打分

先选**你是男是女**，再按该性别的审美标准打分。

为什么要选性别？因为**面部二态偏好在男女之间是反的**：文献显示男性偏好女性化的面部特征，女性偏好更男性化的面部二态。所以同一个分数，用的是两套尺子。

## 评分依据

### 女性化程度（7 项）

方向来自**面部女性化手术（FFS）文献**中记载的男女形态差异：

| 指标 | 权重 | 男性向 | 女性向 |
|---|---|---|---|
| 下颌角宽 / 颧宽 | 26% | 0.84 | 0.75 |
| 下颚宽 / 颧宽 | 16% | 0.72 | 0.63 |
| 下巴方度（宽/高） | 16% | 2.30 | 1.95 |
| 下巴长 / 面高 | 12% | 0.26 | 0.22 |
| 外眼角倾斜 | 10% | +2° | −4° |
| 眼裂高宽比 | 10% | 0.32 | 0.38 |
| 鼻宽 / 鼻长 | 10% | 0.60 | 0.50 |

**骨骼占 70%**——这符合 FFS 的实际逻辑：改变性别观感的是骨相，不是五官修饰。

### 颜值分（分性别）

参考 **Grammer 等人提出的「美貌八支柱」** 中可测量的四项：

- **对称性**（30%）—— Grammer & Thornhill, 1994
- **比例规整**（20%）—— 近似"平均性"
- **性别二态**（25%）—— 方向按性别翻转
- **皮肤状态**（15%）
- 唇鼻比例（10%）

### 不做进主分的项

**面宽/面高比（fWHR）** 和 **下颌角角度** 在学术上存在性二态争议（有研究认为男女差异不显著），所以只在结果的"原始测量"里列出参考值，**不计入分数**。

## 隐私

- **全部在本地计算**，模型直接内嵌在安装包里，第一次打开也不需要联网
- 图片只在内存里算一次，**不上传、不写入相册、不留缓存**
- 关掉页面即销毁
- 没有任何账号系统、没有埋点、没有广告

---

## 技术实现

- **人脸检测与关键点**：[@vladmandic/face-api](https://github.com/vladmandic/face-api)（MIT）
  - TinyFaceDetector + 68 点关键点模型
  - 模型以 base64 内嵌，通过拦截 `fetch` 离线加载
- **计算后端**：优先 WebGL；先用原生编译一个小 shader 做探针，失败自动退回 CPU（低端机也能跑）
- **Android 外壳**：WebView + `onPermissionRequest` 授予相机 + `onShowFileChooser` 接相册
- **头部歪斜校正**：用双眼内眼角连线算 roll，把所有关键点旋转回正再测量

## 自己构建

```bash
npm install
npm run build
# 产物：dist/面值.html（单文件，2.1 MB，含模型和图标）
```

Android 工程在 [`android/`](android/)，是一个 WebView 壳：

```
android/
├── AndroidManifest.xml
├── java/com/facemetric/app/MainActivity.java
└── res/  (layout / values / mipmap 图标)
```

把 `dist/面值.html` 复制成 `assets/index.html`，然后用 aapt / javac / d8 / apksigner 打包即可。

**APK 下载**：见 [Releases](../../releases)。

## 已知局限

这个工具我尽量做诚实，所以这些必须写出来：

- **锚点是启发式标定**，不是经过临床验证的量表。方向对，具体刻度还需要更多样本校准
- **分数不是审美判决**，也不是医学诊断
- 同一张脸在不同光线、角度、镜头焦距下结果会有差异
- 这是**单张 2D 照片**的几何分析，拍不到骨头，所有"骨相"都是从可见轮廓反推的

**它不能定义你，也不该被任何人拿来定义你。**
